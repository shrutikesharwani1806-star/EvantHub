🎟️ MoodGo – MERN Stack Event & Movie Booking Platform

MoodGo is a full-stack MERN (MongoDB, Express, React, Node.js) application inspired by district-level entertainment platforms.

It allows users to:

🎬 Book movie tickets

🎉 Book event tickets

📢 Create & submit their own events

✅ Get events approved by admin

MoodGo aims to build a unified entertainment & community-driven event ecosystem.
